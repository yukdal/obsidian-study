# 차근차근 옵시디언

옵시디언 초보자가 웹에서 배우고 실제 옵시디언에 적용하는 개인 학습 웹앱입니다.

**접속:** https://yukdal.github.io/obsidian-study/

## 제공하는 것

- 기본 과정 16개 수업과 필요할 때 고르는 선택 과정 6개
- 개념 설명, 실습 안내, 복사·다운로드할 Markdown 예시
- 수업별 체크·메모·완료 상태, 데일리 노트 7일 기록
- 학습 지도, 내 세팅 현황, 자료실, 용어집
- 학습 기록 Markdown 내보내기, JSON 백업·복원

## 사용 방법

1. 첫 방문에는 **첫 수업 시작하기**를 누릅니다.
2. 웹앱의 안내를 읽고 실제 옵시디언에서 실습합니다.
3. 실습 체크와 메모를 남기고 완료합니다.
4. **내 기록 → 전체 기록 JSON 백업**으로 학습 기록을 보관합니다.

진도와 메모는 현재 기기의 브라우저에 저장됩니다. 같은 주소에 접속해도 다른 기기와 자동 공유되지는 않습니다. 브라우저 데이터를 지우기 전에 JSON 백업을 받아 주세요. 다른 기기에서는 해당 파일을 선택해 내용을 확인한 뒤 복원합니다. 복원하면 기존 기록 전체가 백업 내용으로 바뀝니다.

웹앱 학습 기록과 실제 옵시디언 볼트는 별도로 관리됩니다. 기본 과정은 16개 수업을 기준으로 계산하며 선택 과정은 완료하지 않아도 기본 과정이 100%가 됩니다.

## 자료와 구현

수업별 출처를 제공하며 외부 자료의 저작권은 각 제작자에게 있습니다. 자료실의 '임베드 확인'은 영상 존재와 임베드 허용을 확인한 상태이고, 실제 내용 검토를 뜻하지 않습니다. '미확인'은 접근 가능 여부와 내용을 확인하지 않은 자료입니다.

빌드 도구·서버·Firebase 없이 HTML, CSS, JavaScript와 브라우저 저장소로 동작하며 GitHub Pages에서 배포합니다. 원본 소스의 index.html을 브라우저에서 직접 열어 사용할 수도 있습니다. 파일로 연 기록과 배포 주소에서 연 기록은 별도로 저장되므로 이전 기록이 있으면 JSON 백업으로 옮겨 주세요.
