# 차근차근 옵시디언

옵시디언 초보자가 웹에서 배우고 실제 옵시디언에 적용하는 개인 학습 웹앱입니다.

**[학습 시작하기](https://yukdal.github.io/obsidian-study/)**

## 제공하는 것

- 기본 16개·선택 6개 수업, 개념 설명과 실습 안내
- 복사·다운로드할 Markdown 예시, 자료실과 용어집
- 수업별 체크·메모·완료 상태, 데일리 노트 7일 기록
- 학습 기록 Markdown 내보내기, JSON 백업·복원
- 기존 구글 계정의 Google Drive를 통한 기기 간 학습 기록 동기화

## 사용 방법

1. 첫 방문에는 **첫 수업 시작하기**를 누릅니다.
2. 웹앱 안내를 읽고 실제 옵시디언에서 실습한 뒤 체크와 메모를 남깁니다.
3. PC와 휴대폰에서 **Google Drive 동기화 → 구글 계정으로 연결**로 같은 계정을 연결합니다.
4. 연결하기 전에 작성한 기록을 옮기려면 **로그인 전 기록 가져오기**를 누릅니다.
5. **내 기록 → 전체 기록 JSON 백업**으로 사본도 보관합니다.

현재 개인 테스트용으로 등록된 본인 계정만 연결할 수 있습니다. 로그인 없이도 전체 수업과 브라우저 저장을 사용할 수 있습니다. 첫 연결에는 구글 테스트 앱 안내가 나타날 수 있습니다.

연결 중 변경 내용은 자동 전송되고 다른 기기의 기록은 화면이 열려 있을 때 약 20초마다 확인합니다. 새로고침하거나 권한이 만료돼도 마지막 계정의 기록이 그대로 보이고, 그동안의 수정은 기기에 보관했다가 **다시 연결**하면 전송합니다. [동기화 사용 안내](./Google%20Drive%20동기화%20안내.md)를 참고하세요.

구글 계정별 기록과 로그인 전 기록은 분리됩니다. 같은 항목을 동시에 다르게 수정하면 선택할 수 있도록 양쪽 내용을 보존합니다. 브라우저 데이터를 지우기 전에는 전송 완료 여부를 확인하고 JSON 백업을 받으세요. JSON 복원은 현재 계정 또는 로그인 전 기록을 백업 내용으로 교체하며, 연결된 계정의 변경은 Drive에도 반영됩니다.

웹앱의 학습 기록과 실제 옵시디언 볼트는 별도로 관리합니다. 이 기능이 옵시디언 노트 파일을 동기화하지는 않습니다. 기본 과정 완료율에는 선택 수업이 포함되지 않습니다.

## 자료와 구현

수업마다 출처를 제공합니다. 자료실의 '임베드 확인'은 영상 존재와 임베드 허용 여부를 확인한 상태이며 실제 내용 검토를 뜻하지 않습니다. '미확인'은 접근 가능 여부와 내용을 확인하지 않은 자료입니다.

HTML·CSS·JavaScript를 GitHub Pages로 배포합니다. Firebase, 별도 서버, 추가 저장 서비스 계정은 사용하지 않습니다. 구글 로그인에는 Google Identity Services, 저장에는 Drive의 앱 전용 공간을 사용합니다. OAuth 클라이언트 ID는 공개 설정이며 로그인 토큰은 메모리에서만 사용합니다.

index.html을 직접 열면 로컬 학습 기능을 사용할 수 있습니다. 구글 연결은 배포 주소에서 사용하세요. 파일로 연 기록과 배포 주소의 기록은 저장 공간이 다르므로 JSON 백업으로 옮깁니다.
